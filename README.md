# Wishlist Conversion MVP

A navigable mobile prototype exploring wishlist re-engagement and fit-aware product comparison for fashion commerce.

## Run locally

```bash
npm install
npm run dev
```

The development server runs at `http://localhost:5173` by default.

## Production build

```bash
npm run build
```

The deployable output is generated in `dist/`.

## Prototype routes

- `/` — Home and wishlist re-engagement nudge
- `/wishlist` — Wishlist
- `/collection` — Collection
- `/pdp` — Product details
- `/reviews` — Ratings and reviews
- `/better-matches` — Fit-aware comparison

All product and review content is static prototype data. Reviewer identities are anonymized.
